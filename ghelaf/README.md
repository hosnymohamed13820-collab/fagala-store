# غلاف

فولدر شخصي — منفصل تماماً عن مشروع الفجالة ستور.

## غلاف After Hours — ريلمي GT ماستر إديشن

| الملف | فيه إيه |
|---|---|
| `cover_print.png` | **ملف الطباعة** — ٧٩٫٥×١٦٥٫٢ مم (الموبايل ٧٣٫٥×١٥٩٫٢ + ٣ مم نزيف) بدقة ~٦٠٠ dpi |
| `preview.png` | معاينة على شكل الموبايل + مكان الكاميرا **تقريبي** |
| `cover.html` | التصميم نفسه (الكلام فيكتور) — عدّل فيه وارندر تاني |
| `photo.png` | الصورة بعد ما اتشال منها الكلام (`prep_photo.py`) |
| `ref.jpg` | البوستر الأصلي |

ارندر: `NODE_PATH=$(npm root -g) node render.js`
