# زاحف واجهة الفجالة ستور (بند ٨٠١)

أداة فحص واجهة المستخدم والانحدار والتأكد من أمان النظام قبل أي رفع على السيرفر الحي.

---

## الهدف
- الدخول للموقع المحلي كمستخدم فعلي.
- الزحف التلقائي على جميع صفحات الموقع (من القائمة الجانبية والهيدر + الروابط الداخلية).
- الضغط على جميع الأزرار والتبويبات وتغيير الفلاتر والتأكد من عدم وجود أخطاء صامتة.
- التقاط ٤ صور كاملة لكل صفحة (ديسكتوب وموبايل × وضع فاتح ووضع ليلي).
- 🔴 **حارس الأمان التام:** قفل ومنع أي عملية كتابة أو تعديل مالي/مخزني لحماية الداتابيز.

---

## المتطلبات
- **Node.js** (v18 فأعلى).
- **Edge** مثبت على الجهاز (لا حاجة لتحميل أي متصفح عبر Playwright).
- **PHP 8.3** (سيرفر Laragon أو PHP CLI).

---

## طريقة التشغيل

### ١) الفحص الكامل كمستخدم داخل (مالك أو مدير فرع):
```bash
# باستخدام حساب واحد
CRAWL_USER=admin CRAWL_PASS=your_secret_password bash tests/local/crawl/crawl.sh

# أو عدة حسابات وأدوار
CRAWL_USERS="admin:pass1,bonjour_user:pass2" bash tests/local/crawl/crawl.sh --roles owner,bonjour
```

### ٢) فحص ما قبل الدخول وشاشة الدخول فقط:
لو لم يتم تمرير `CRAWL_USER` و `CRAWL_PASS`، ستقوم الأداة باختبار الحارس واختبار صيد الأخطاء وفحص شاشة الدخول فقط وتوليد التقرير:
```bash
bash tests/local/crawl/crawl.sh
```

---

## الخيارات الإضافية (CLI Flags)
- `--max-pages 150`: أقصى عدد صفحات للزحف (الافتراضي: 150).
- `--max-clicks 40`: أقصى عدد ضغطات لكل صفحة (الافتراضي: 40).
- `--roles owner,bonjour`: الأدوار المراد زحفها بالتتابع.
- `--port 8095`: منفذ السيرفر المحلي (الافتراضي: 8095).
- `--skip-shots`: تخطي التقاط لقطات الشاشة لتسريع الفحص.

---

## المخرجات والتقارير
- `tests/local/crawl/out/report.html`: تقرير مرئي كامل في صفحة واحدة بدون مكاتب خارجية.
- `tests/local/crawl/out/report.json`: بيانات الفحص كاملة بصيغة JSON.
- `tests/local/crawl/out/shots/`: لقطات الشاشة الأربعة لكل صفحة:
  - `<page>_1440_light.png`
  - `<page>_1440_dark.png`
  - `<page>_390_light.png`
  - `<page>_390_dark.png`

---

## حارس الأمان (Data Guard)
- يقفل فوراً أي طلب `POST` / `PUT` / `PATCH` / `DELETE` ما عدا صفحة الدخول `login.php`.
- يقفل أي طلب `GET` يحتوي على كلمات حساسة مثل (`logout`, `delete`, `pay`, `approve`, `reject`, `reverse`, إلخ).
- يفحص عدادات الجداول الخمسة المالية الحساسة قبل وبعد الرن للتأكد من تطابقها التام وعدم كتابة أي سجل:
  1. `journal_entries`
  2. `push_queue`
  3. `sale_docs`
  4. `notifications`
  5. `activity_log`
