# فحوصات ما قبل التسليم

```bash
bash tests/run_all.sh
```

شغّلها **قبل رفع أي ملف**، وقبل ما أي وكيل (Antigravity / Claude) يوريك كوده.

## ليه موجودة

التلات بقات دي وصلوا للسيرفر في جلسة واحدة (2026-08-23)، وكلهم
كان الفحص بيمسكهم في ثانية:

| البق | إيه اللي حصل |
|---|---|
| `$sumWallet` | شيلت المحفظة وفاتني خلية في صف الإجماليات |
| `$mainTrId` | `?>` جوه تعليق `//` قفل وسم PHP، والباقي اتطبع كنص |
| `$prov` | الاستعلام ٥ علامات `?` والـexecute بيبعت ٦ قيم |

كل واحد فيهم كلّف لفة كاملة: ترفع ← تشوف الخطأ ← تبعتهولي ← أشخّص
← أصلّح ← تعيد الرفع.

## اللي بيتفحص

- **بنية PHP** — الأقروس · الوسوم · `?>` جوه تعليق وبعده كود
- **بنية PowerShell** — الأقواس · here-strings · backtick وراه مسافة
- **مسارات الخروج** — أي `exit` في وكيل مزامنة من غير نبضة
- **ترميز باورشيل** — عربي من غير BOM بيكسر الحروف
- **الجافاسكربت** — `node --check`

## قواعد اتعلمناها من الإنذارات الكاذبة

الفاحص نفسه اتصلّح ٤ مرات لما طلع بيدي إنذارات غلط:

1. **`<?php` مفتوح في الآخر = سليم** — ده الشكل الموصى بيه لملفات
   PHP الخالصة، مش خطأ.
2. **`<?php else: // cats ?>` = سليم** — الوسم بيتقفل بإرادة الكاتب.
   البق هو `?>` **وبعده كود** في نفس السطر.
3. **عربي + BOM في باورشيل = سليم** — وكلاء السكانر شغّالين كده.
   البق هو عربي **من غير** BOM.
4. **فحص النبضة لوكلاء المزامنة بس** — سكربتات التركيب مالهاش نبضة.

⚠️ لو الفاحص دلّك على حاجة، **اتأكد إنها بق حقيقي قبل ما تصلّح**.
   نص إنذارات أول يوم كانت كاذبة.

## إضافة فحص جديد

أي بق يوصل للسيرفر مرتين = يستاهل فحص. ضيفه في `check_php.py` أو
`check_ps1.py` واعمل حالة اختبار تثبت إنه بيمسكه فعلاً.
