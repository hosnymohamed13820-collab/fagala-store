# مراجعة وتسليم شغل الوكيل — الفجالة ستور

## القاعدة في سطر

> **متصدّقش تقرير الوكيل.** هو بيقول «✅ كل الفحوصات عدّت» وهو **مشغّلهاش**،
> وبيقول «ما لمستش حاجة» وهو لامس. **شغّل الجيت بنفسك، واقرا الدايف.**

---

## الترتيب

### ٠) الفحص الآلي — أول أمر، قبل ما تقرا أي دايف

```bash
bash tests/local/land_check.sh <N>       # N = رقم البريف
```

بيعمل ٤ حاجات كانت بتتكتب بإيد كل مرة: `git status` مقابل بلوك «المتوقع بالحرف»
في البريف · ملفات `ashraqa/` اللي بقت نسخة من `site/` وهي كانت مختلفة (حصلت في ٤٤
مع `definitions.php`) · اتساق أرقام الكاش في الموقعين · `run_all.sh`.
لو ❌ في ٢ ← رجّع ملف إشراقة من `HEAD` وطبّق تعديلات البريف بس عليه.
لو CSS/JS اتغيّر من غير ما الكاش يتزوّد ← `bash tests/local/bump_cache.sh "وصف" <الملفات>`.
بعده كمّل بالخطوات تحت (هي اللي بتحتاج عين: الدايف · الفلوس · الممنوعات).

**لو البريف لمس شكل صفحة (CSS · HTML · ستايل جوّه صفحة):** صوّرها واقرا الصورة بنفسك قبل الكوميت:
```bash
bash tests/local/sync_to_laragon.sh
SHOT_DIR="<scratchpad>/shots" bash tests/local/shot.sh <page.php>        # فاتح + ليلي
```
دوّر على: رقم مش في مكانه · كتابة لازقة في حرف الكارت · زرار عريان · لون بيختفي في الليلي.
(اتعملت ٢٣ سبتمبر بعد رقم في cashier.php محدش شافه غير محمد على الموقع.)

### ١) النطاق — قبل أي حاجة تانية

```bash
git status --porcelain
git diff --numstat
```

- الملفات **مطابقة للمتوقع في البريف**؟ ملف زيادة = خروج عن البريف.
- 🔴 **مفيش سطر بيبدأ بـ`D`.**
- الملفات اللي البريف قال «متلمسهاش» — `numstat` بتاعها **زي ما كان**؟
- عدد السطور معقول؟ «تعديل سطر واحد» طلع `200+` = فيه حاجة تانية اتعملت.

### ٢) الممنوعات — بالـ`grep` مش بالثقة

```bash
grep -rn "DELETE\|ALTER TABLE\|CREATE TABLE" site/الملفات_اللي_اتغيّرت
grep -rn "require_permission(" site/ | wc -l     # العدد المتوقع
```

### ٣) الأيقونات والمتغيّرات — بتعدّي صامتة

أيقونة مش في الـsubset = **مربع فاضي**. متغيّر CSS مش موجود = **الخاصية
بتتجاهل من غير خطأ**. الاتنين مابيبانوش في أي فحص.

```bash
# أيقونات ناقصة
grep -oE "ti-[a-z0-9-]+" site/الملف.php | sort -u > /tmp/i.txt
grep -oE "ti-[a-z0-9-]+" site/assets/tabler-subset.css | sort -u > /tmp/s.txt
comm -23 /tmp/i.txt /tmp/s.txt

# متغيّرات CSS ناقصة
grep -oE "var\(--[a-z0-9-]+\)" site/الملف.php | sed 's/var(--\(.*\))/\1/' | sort -u > /tmp/v.txt
grep -oE "\-\-[a-z0-9-]+:" site/assets/fagala.css | sed 's/--\(.*\):/\1/' | sort -u > /tmp/a.txt
comm -23 /tmp/v.txt /tmp/a.txt
```
ولو الصفحة جديدة: **`.btn` معرّف جوّاها؟** وأي كلاس زرار بيعرّف `color`
**ليه `:hover`؟**

### ٣.٥) الـservice worker — أربع أماكن لازم يتغيّروا مع بعض

لو الديف لمس **`site/sw.js`**:

```bash
grep -n "const VERSION" site/sw.js
grep -o "sw.js?v=[0-9]*" site/includes/header.php site/login.php site/settings.php
```

🔴 **الأربعة لازم يبقوا نفس الرقم.**
- `VERSION` اتزوّد و`?v=` لأ ← كاش الاستضافة (LiteSpeed) بيرجّع الملف
  القديم والمتصفح عمره ما يشوف الجديد.
- `?v=` اتزوّد و`VERSION` لأ ← المتصفح بيجيب نفس المحتوى ومايحدّثش.

يوم ٣١ أغسطس ده كلّف جلسة كاملة: كل فحوص الإشعارات كانت **خضرا**
والإشعارات ميتة، لأن النسخة اللي على السيرفر غير النسخة الشغالة.
والوكيل عدّل `sw.js` وساب `VERSION` زي ما هي **رغم تحذير صريح في البريف**.

### ٣.٦) الفحص لازم يسأل بنفس العنوان

أي كود فحص بيجيب أصل (`sw.js`, `fagala.css`, …) لازم يجيبه **بنفس
العنوان اللي بيتحمّل بيه فعلاً**. فحص بعنوان مبستّت (`?_=<توقيت>`)
بيعدّي من الكاش وبيطمّنك على حاجة **مش** اللي بتحصل للمستخدم.

### ٤) الجيت — شغّله إنت

```bash
export PYTHONIOENCODING=utf-8 && bash tests/run_all.sh
```
لازم «✅ كل الفحوصات عدّت». الجيت بيمسك بنية PHP بس — **مش بيمسك منطق**،
فالخطوة الجاية مش اختيارية.

### ٥) الفلوس — لو الدايف قرّب من مرتب أو خزينة أو سلفة

اقرا الكود بعينك ودوّر على:

- 🔴 **قيمة سالبة داخلة معادلة طرح.** المرتب بيطرح السلف، وطرح السالب
  **بيجمع**: `9,000 − (−55,978) = 64,978`. لازم يكون فيه فحص «لو سالب،
  الخصم صفر».
- 🔴 **الشاشة والصرف بيطلعوا نفس الرقم؟** أي قاعدة خصم لازم تتطبّق في
  `compute_salary()` **و**`pay_salary()` **و**`$advMap` في `hr.php`.
  واحد منهم ناقص = الشاشة بتقول حاجة والصرف بيعمل حاجة.
- **الفرق مش القيمة الجديدة** في أي تعديل رصيد.
- **القيمة بتتقرا قبل التصفير** مش بعده.
- **الرقم المقرّب للعرض مابيرجعش للسيرفر** ويتصرف بيه.
- **استعلام جوه حلقة** — `foreach` فيه `->prepare` أو `->query`.
- **حماية العملية مش الواجهة بس** — إخفاء زرار مش حماية.
- **أعمدة `INT` بتستقبل كسور** — بتتقرّب في صمت.

### ٦) الكوميت

بالعامية، وبيشرح **ليه** مش **إيه**. الشكل اللي ماشي في الريبو:
سطر عنوان قصير، وفقرة بتقول المشكلة كانت إيه بالأرقام، وفقرة بتقول
الحل، وتحذير 🔴 لو فيه حاجة خطيرة.

```
Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
Claude-Session: <رابط الجلسة>
```

### ٧) قايمة الرفع

```bash
cd site && for f in $(find . -maxdepth 1 -name "*.php" | sed 's|^\./||' | grep -v "^config.php$"); do
  if [ ! -f "../public_html/$f" ]; then echo "جديد:  site/$f"
  elif ! diff -q "$f" "../public_html/$f" >/dev/null 2>&1; then echo "معدّل: site/$f"; fi
done
for f in includes/*.php; do [ -f "../public_html/$f" ] && ! diff -q "$f" "../public_html/$f" >/dev/null 2>&1 && echo "معدّل: site/$f"; done
for f in assets/*; do b=$(basename "$f"); [ -f "../public_html/assets/$b" ] && ! diff -q "$f" "../public_html/assets/$b" >/dev/null 2>&1 && echo "معدّل: site/assets/$b"; done
diff -q sw.js ../public_html/sw.js >/dev/null 2>&1 || echo "معدّل: site/sw.js"
```

🔴🔴 **`config.php` مستثنى عن قصد.** المحلي ملف وهمي ٣٠ بايت للاختبارات،
واللي على السيرفر الحقيقي ١٦ كيلو. **رفعه بيوقّع الموقع في ثانية.**
غلطة كادت تحصل — المقارنة الساذجة بتطلّعه في القايمة.

**وكمّل القايمة بـ:**
- ملفات `local/*.sql` المطلوب تنفيذها **من phpMyAdmin — مابتترفعش**،
  وبالترتيب لو واحد بيعتمد على التاني
- 🔴 **الـSQL قبل الملفات** لو الكود بيستعمل عمود/جدول جديد
- `?v=` في الصفحة و`VERSION` في `sw.js` **بس لو ملف في `assets/` أو
  `sw.js` اتغيّر**. تعديل جوّه بلوك `<style>` في صفحة PHP **مش محتاج** —
  صفحات PHP مابتتكاشش
- خطوات تجربة مرقّمة، أولها **«حاجة شغالة دلوقتي — قارن الرقم قبل وبعد»**

## 🔴 وانت مستني الوكيل: **متلمسش أي ملف**

الوكيل بيعمل `git restore` وبيمسح **أي تعديل مش متعمّله كوميت** — حتى
الملفات اللي برّه نطاقه. حصل ٣١ أغسطس: كلود عدّل `auth.php` وagy كان
شغال على بريف تاني، فالتعديل اختفى. اللي نجا كان متعمّله كوميت.

**القاعدة:** استنى الرن يخلص، أو اعمل كوميت لشغلك **قبل** ما تبعت البريف.

🔴 **ومترفعش وهو شغّال.** `deploy.sh` بيرفع اللي على الجهاز مش الكوميت. ٢٣ سبتمبر:
رفعت تعديل ألوان وأجي كان بدأ ٤٥ ← `finance.php` و`cashier.php` و`treasury.php`
اترفعوا نص مكتوبين. لو `git status` فيه أي ملف مش من كوميتك ← **متفرعش**.
تصليح طارئ لملف واحد على السيرفر:
`git show HEAD:site/f.php | ssh … "cat > f.php.tmp && php -l f.php.tmp && mv f.php.tmp f.php"`.

## حاجات بتوقعك

- **الوكيل بيرجع `killed` والشغل نزل فعلاً.** اتأكد بـ`git status` قبل
  ما تعيد. ولو `killed` من غير شغل ← **قول لمحمد يشيك على الرام**.
- **الشجرة نص-نص.** لو الرن اتقطع في النص، **متعملش كوميت** — نص فيتشر
  مالوش لازمة في التاريخ. اكتب تكملة بالناقص.
- **`public_html/` مش git** — هي نسخة السيرفر. لو ملف فيها **مختلف**
  يبقى محمد ما رفعوش لسه، مش إن فيه مشكلة.
- **الوكيل بيصلّح ملف وينسى إخواته.** لو المهمة على `reports.php`، دوّر
  على الصفحات اللي بتتنده منها:
  `grep -oE "[a-z_]+\.php" site/reports.php | sort -u`
