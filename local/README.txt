السلام عليكم. الملف ده هيشرحلك كل حاجة بالتفصيل من الصفر.
اقرأه بهدوء وانفّذ خطوة خطوة، ولو وقفت في أي حاجة ارجع للقسم بتاعها.


══════════════════════════════════════════════════════════════════
  الجزء الأول: إيه هو النظام ده؟
══════════════════════════════════════════════════════════════════

ده نظام مالي متكامل لمكتبات الفجالة ستور، بيشتغل من المتصفح
(على الكمبيوتر والموبايل على نفس شبكة الواي فاي).

النظام بيشتغل بقاعدتين بيانات في نفس الوقت:

  1) قاعدة MySQL (بتاعتنا إحنا):
     فيها كل اللي بنعمله — الخزائن، الورديات، العهد، الموردين،
     الموظفين، الجرد... إلخ. دي القاعدة الأساسية للنظام.

  2) قاعدة SQL Server (نظامكم الحالي):
     النظام بيقرا منها بس (مش بيكتب فيها) — الأصناف، الأسعار،
     الباركود، فواتير الاستلامات. دي بتاعت برنامج المحاسبة عندكم.

الربط بين الاتنين بيتم في 3 أماكن:
  • استعلام الأسعار: بيقرا الباركود والسعر.
  • الاستلامات: بتقرا الفواتير وأصنافها.
  • الجرد: بيقرا الأصناف والوحدات.


══════════════════════════════════════════════════════════════════
  الجزء الثاني: المتطلبات (إيه اللي محتاج تركّبه)
══════════════════════════════════════════════════════════════════

1) برنامج XAMPP (فيه Apache + MySQL + PHP).
   نزّله من: https://www.apachefriends.org

2) لو هتستخدم استعلام الأسعار والاستلامات والجرد (الربط بنظامكم):
   محتاج تفعّل امتداد اسمه "pdo_sqlsrv" في PHP.
   (لو لسه مش جاهز، النظام هيشتغل عادي، بس الصفحات دي هتقولك إن
    الاتصال بـ SQL Server مش متظبط — وده طبيعي لحد ما تظبطه).


══════════════════════════════════════════════════════════════════
  الجزء الثالث: تركيب ملفات الموقع
══════════════════════════════════════════════════════════════════

1) افتح فولدر XAMPP (عادةً C:\xampp).
2) ادخل فولدر "htdocs".
3) اعمل فولدر جديد اسمه "fagala".
4) فك ضغط الملف ده وحط كل الملفات جوّا فولدر fagala.

   المفروض يبقى عندك المسار كده:
   C:\xampp\htdocs\fagala\  (وجواه login.php و config.php... إلخ)

5) شغّل XAMPP، ودوس "Start" على Apache و MySQL.


══════════════════════════════════════════════════════════════════
  الجزء الرابع: إنشاء قاعدة البيانات (مهم جداً، بالترتيب)
══════════════════════════════════════════════════════════════════

1) افتح المتصفح واكتب: http://localhost/phpmyadmin

2) هنستورد ملفات الـ SQL بالترتيب ده بالظبط (واحد ورا التاني):

   أ) database.sql
      (ده بينشئ قاعدة البيانات "fagala_store" وكل الجداول الأساسية)
      • دوس "Import" (استيراد) فوق
      • اختار ملف database.sql
      • دوس "Go" (تنفيذ)

   ب) treasuries_seed.sql
      (بينشئ الخزائن المركزية الخمسة: كاش، فيزا، إنستا، محفظة، كارت)

   ج) upgrade_hr.sql
      (بيضيف مواعيد عمل الموظفين + جدول طلبات تصحيح الحضور)

   د) upgrade_reconcile.sql
      (بيضيف جدول التسويات)

   هـ) upgrade_stocktake.sql
      (بيضيف جداول الجرد الأربعة)

   ملاحظة: لو نفّذت database.sql وبعدين عايز تستورد الباقي،
   اختار قاعدة "fagala_store" من الشمال الأول وبعدين Import.


══════════════════════════════════════════════════════════════════
  الجزء الخامس: ربط النظام بقاعدة بياناتكم (SQL Server)
══════════════════════════════════════════════════════════════════

افتح ملف config.php بأي محرر نصوص (Notepad++ مثلاً) وعدّل:

  • بيانات MySQL (لو مختلفة عن الافتراضي — غالباً مش هتحتاج تغيّرها):
    DB_HOST = 'localhost'
    DB_NAME = 'fagala_store'
    DB_USER = 'root'
    DB_PASS = ''   (فاضي في XAMPP عادةً)

  • بيانات SQL Server (دي بتاعت برنامج المحاسبة عندكم):
    SQLSRV_HOST = 'اسم السيرفر أو الـ IP'
    SQLSRV_DB   = 'اسم قاعدة البيانات'
    SQLSRV_USER = 'اسم المستخدم'
    SQLSRV_PASS = 'كلمة السر'

    (لو مش عارف البيانات دي، اسأل اللي بيدير برنامج المحاسبة عندكم.
     ولو سيبتها فاضية، باقي النظام يشتغل عادي بس الأصناف/الأسعار/
     الجرد مش هيلاقوا بيانات).


══════════════════════════════════════════════════════════════════
  الجزء السادس: إنشاء حساب المدير (الأونر) — مرة واحدة بس
══════════════════════════════════════════════════════════════════

1) افتح المتصفح واكتب: http://localhost/fagala/setup.php

2) هيقولك إنه أنشأ حساب المدير:
   • اسم المستخدم: owner
   • كلمة السر:   admin123

3) **مهم للأمان**: بعد ما تتأكد إنه اشتغل، احذف ملف setup.php
   أو غيّر اسمه (مثلاً setup_old.php) عشان محدش يقدر يستخدمه تاني.

4) ادخل وغيّر كلمة السر من صفحة المستخدمين.


══════════════════════════════════════════════════════════════════
  الجزء السابع: الدخول واستخدام النظام
══════════════════════════════════════════════════════════════════

ادخل من: http://localhost/fagala/login.php
بـ: owner / admin123

أول حاجة تعملها (بالترتيب ده مفيد):

  1) التعريفات → أضف الفروع (كل فرع هيتعملّه خزينة عهدة تلقائياً).
  2) التعريفات → أضف الموظفين (بمواعيدهم وربطهم بحسابات مستخدمين).
  3) المستخدمون → أنشئ حسابات للكاشيرية والمحاسبين والمراجعين.
  4) الإعدادات → اضبط أي إعدادات (زي حد تحمّل عجز العهدة).


══════════════════════════════════════════════════════════════════
  الجزء الثامن: التشغيل على الموبايل (نفس شبكة الواي فاي)
══════════════════════════════════════════════════════════════════

1) على الكمبيوتر اللي شغّال عليه XAMPP، اعرف الـ IP بتاعه:
   افتح Command Prompt واكتب: ipconfig
   ودوّر على "IPv4 Address" (مثلاً 192.168.1.5)

2) على الموبايل (المتصل بنفس الواي فاي)، افتح المتصفح واكتب:
   http://192.168.1.5/fagala/login.php
   (غيّر الـ IP باللي طلعلك)

ملاحظة عن سكانر الكاميرا في استعلام الأسعار:
   المتصفحات بتمنع الكاميرا إلا على HTTPS (اتصال آمن).
   فلو الكاميرا مفتحتش على الموبايل، ده طبيعي — اكتب الباركود بإيدك
   وهيشتغل عادي. (تفعيل HTTPS محتاج إعداد إضافي).


══════════════════════════════════════════════════════════════════
  الجزء التاسع: الموديولات (إيه اللي بيعمله كل واحد)
══════════════════════════════════════════════════════════════════

• لوحة القيادة (Dashboard):
  مرجع سريع للمدير المالي. بيوريك الخزينة الرئيسية (إجمالي كل
  الخزائن)، وكل خزينة فرعية، وبارات عهد الفروع بالألوان (أخضر/
  برتقالي/أحمر حسب المتبقي)، وملخص اليوم، وحالة التقفيلات.

• استعلام الأسعار:
  للكاشير. يكتب الباركود أو يمسحه بالكاميرا، فيظهر اسم الصنف وسعره.

• تقفيل الكاشير:
  الكاشير يقفّل ورديته (الكاش بالفئات + وسائل الدفع + الفرق).

• مراجعة المحاسب:
  المحاسب يراجع تقفيل الكاشير، يكتب الأرقام الفعلية، يعتمد أو يرفض.
  أرقام المحاسب هي اللي بتدخل الخزينة.

• عهدة الفروع:
  إذن صرف للفرع (الكاش ينقص، العهدة تزيد) → مصروفات من العهدة →
  إقفال شهري (الفرق بيتحسب، والعجز ممكن يتسجّل على الموظف).

• الخزينة:
  كل حركات الفلوس وكشف الحساب. استلام/صرف/تحويل بين الخزائن.

• التسويات:
  مقارنة رصيد الخزينة الدفتري بالفعلي المعدود، وتصحيح أي فرق.

• الموارد البشرية:
  الموظفين، السلف، الجزاءات، الإجازات، الرواتب (بتخصم تلقائياً)،
  وطلبات تصحيح الحضور.

• تسجيل الحضور:
  واجهة الموظف (حضور/انصراف + ساعات العمل بالدقيقة + طلب تصحيح).

• الموردون:
  فواتير الموردين (كاش/آجل)، أرصدتهم، والفواتير من الاستلامات.

• الاستلامات:
  بتقرا فواتير الشراء من نظامكم، وتوزّع الأصناف على الفروع،
  وتنزّل لكل فرع ملف TEXT بالكميات.

• الجرد:
  الأونر يبدأ جلسة جرد (ويرفع ملف رصيد اختياري) → الموظفون يعملوا
  محاضر جرد ويعدّوا الأصناف (الكود بيجيب الاسم والوحدة تلقائياً،
  والأكواد المربوطة بتتجمّع) → المراجعة (مقارنة بالألوان وتعديل)
  → طباعة تقرير TEXT لكل محضر أو مجمّع لكلهم.

• التقارير:
  6 تقارير (مبيعات، خزينة، عهد، موردين، رواتب، حضور) بفلتر فترة
  وتصدير Excel/CSV.

• التعريفات والإعدادات والمستخدمون:
  إدارة الفروع والموظفين والخزائن، وإعدادات النظام، والمستخدمين.


══════════════════════════════════════════════════════════════════
  الجزء العاشر: ملاحظات مهمة
══════════════════════════════════════════════════════════════════

1) ملف "_خريطة_الترابط.txt":
   بيوضّح أي ملفات مرتبطة ببعض. مفيد جداً لو هتعدّل أي حاجة.

2) أسماء جداول SQL Server:
   لو طلع اسم جدول مختلف عندكم، تقدر تعدّله في أعلى الملفات:
   • الاستلامات → receiving_lib.php
   • الأسعار   → price_lib.php
   • الجرد     → stocktake_lib.php

3) النسخ الاحتياطي:
   اعمل نسخة احتياطية من قاعدة fagala_store بشكل دوري من phpMyAdmin
   (Export).

4) اليوم المحاسبي:
   النظام بيحسب اليوم من 9 صباحاً لـ 9 صباحاً اليوم اللي بعده.

══════════════════════════════════════════════════════════════════
  ملاحظات إضافية (تحديثات)
══════════════════════════════════════════════════════════════════

• الترميز العربي للأصناف:
  لو أسماء الأصناف ظهرت ؟؟؟؟، النظام بيحاول يصلّحها تلقائياً
  (تحويل من Windows-1256 لـ UTF-8). لو لسه فيه مشكلة، تأكد إن
  الـ ODBC DSN بتاعك مضبوط على ترميز يدعم العربي.

• مشكلة الاستلامات "Invalid object name 'STO_TRANS_HEADER'":
  معناها إن جدول الفواتير في قاعدة/schema تانية. الحل:
  افتح receiving_lib.php، ودوّر على SQLSRV_PREFIX (أعلى الملف)،
  وحط البادئة الصح، مثلاً:
     const SQLSRV_PREFIX = 'dbo.';
  أو لو في قاعدة تانية:
     const SQLSRV_PREFIX = 'اسم_القاعدة.dbo.';
  (الجرد والأسعار شغّالين لأنهم يستخدمون ITEM_CODES في القاعدة
   الافتراضية؛ الاستلامات محتاجة الجدول الصح بس).

• خزينة العهدة:
  صرف/استلام العهدة بيتم من شاشة الخزينة (نوع العملية: عهدة لفرع
  / استلام عهدة). وخزائن العهدة مش بتظهر في قائمة "اصرف من" عشان
  المحاسب ميقدرش يصرف من العهدة مباشرة.
